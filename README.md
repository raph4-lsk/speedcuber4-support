## Feedback

Ideas, wishes and bug reports are welcome and read one by one.

| I want to                     | Open                                                                                               |
| ----------------------------- | -------------------------------------------------------------------------------------------------- |
| Share an idea or an opinion   | [Send feedback](https://github.com/raph4-lsk/speedcuber4-support/issues/new?template=feedback.yml) |
| Tell about something broken   | [Report a bug](https://github.com/raph4-lsk/speedcuber4-support/issues/new?template=bug.yml)       |
| See what others already asked | [Open issues](https://github.com/raph4-lsk/speedcuber4-support/issues)                             |

> [!TIP]
> In the app, **Settings › Send feedback** opens the form with your app version, iPhone model and iOS version already filled in.
